# Coranux name and visual identity

The Coranux code is released under the MIT License, but that license does not
grant rights to the “Coranux” name or visual identity.

Official releases published by the project will remain freely available from
the official repository. Forks are welcome. A fork distributed under a
distinctive name may be sold, but it must not be presented as an official
Coranux release or use the Coranux visual identity in a way that causes
confusion.

The MIT License allows redistribution and sale of the code. These naming
guidelines distinguish projects and official releases; they do not generally
prohibit selling the code. Refer to the project repository to identify an
official release.
